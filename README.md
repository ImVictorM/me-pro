## About

This project is my professional portfolio and freelance website.

It was designed to present software development services in a clear and direct
way, showcase selected projects, explain how I work with clients, and provide a
simple way for businesses to get in touch.

## Tech stack

- [Next.js 16](https://nextjs.org/) with App Router
- [React 19](https://react.dev/) and TypeScript
- [Tailwind v4](https://tailwindcss.com/)
- [shadcn/ui](https://ui.shadcn.com/) with [Base UI](https://base-ui.com/)
- [GSAP](https://gsap.com/) for animations
- [React Hook Form](https://react-hook-form.com/) and [Zod](https://zod.dev/) for form handling and validation
- [next-themes](https://github.com/pacocoursey/next-themes) for theme management

## Getting started

### Requirements

- Node.js
- npm

### Local development

Clone the repository

```bash
git clone https://github.com/ImVictorM/me-pro.git && cd me-pro
```

Install the dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Open http://localhost:3000
